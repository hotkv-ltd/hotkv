Disk shows zero writes for every server because persistence was turned off on all of them for the benchmark. These are in-memory stores and nothing was spilling to disk. The number is measured from the kernel per process, not assumed.
Redis and Valkey execute commands on a single thread. Their other threads are I/O threads. They were run as single instances, not as clusters, with the same thread count as the others (all the machine's cores, clamped to each server's maximum). I/O threads can keep cores busy without doing commands, so the CPU and ops-per-CPU-second figures for Redis and Valkey are not a measure of their efficiency, and they can reach higher throughput with fewer I/O threads than they were given here.

Validity checks

These decide which numbers mean anything. A result produced against a full cable, a maxed-out load generator, or an empty keyspace is a measurement of the rig, not the server.

Client-bound: 1 results. The load generator sat at or above 85% CPU on these, so the number is memtier reaching its own limit, not the server reaching its. Read these as a floor. A faster server cannot move them, which is why the change column carries no signal on these rows. Measuring the real ceiling needs more client machines. Affected: PING/HotKV 86%.
Wire-bound: 7 results. Every request and reply crosses the machine's network link, which has a fixed top speed (its bandwidth). At or above 85% of that link the wire, not the server, sets the number: the server could go faster but the network cannot carry more. Read these as a floor (the true server number is higher, and shows on a faster link or at a smaller value size, which puts fewer bytes on the wire per operation), and a ratio between two wire-bound servers means nothing. Note: the "link used" share assumes one speed for both directions; if an instance meters send and receive bandwidth differently, an inbound-heavy write can be flagged here without truly being limited (see the banner or NOTES.md beside this report). Affected: SET/HotKV 115%, GET/HotKV 88%, SETNX/HotKV 136%, RPUSH/HotKV 105%, SADD/HotKV 120%, HSET/HotKV 131%, MSET/HotKV 98%.
