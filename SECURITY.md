# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the scripts in this
repository, please report it privately by emailing **security@hotkv.com** rather
than opening a public issue.

Please include, where possible:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it, including the commit of this repository you used.
- Any proof-of-concept code or logs that help demonstrate the issue.

We will acknowledge your report, investigate, and follow up with next steps and,
once a fix is available, a coordinated disclosure timeline. Please give us a
reasonable amount of time to address the issue before any public disclosure.

## Scope

This policy covers the benchmark scripts in this repository (`harness/` and
`vector-search/scripts/`). For vulnerabilities in the HotKV server or HotKV
Cloud, please also use security@hotkv.com so the report reaches the right team.

Questions about a published benchmark result are not security reports. Please
use the "Report a finding" issue form for those.
